## ✅ Features

- ✓ Browse event organization products and services
- ✓ Categories: Weddings, Engagements, Birthdays, Graduations
- ✓ Shopping cart and wishlist
- ✓ Payment gateway integration
- ✓ Order management and tracking
- ✓ Vendor management (multi-vendor support)
- ✓ Product variants (size, color options)
- ✓ Promo codes and discounts
- ✓ Rating and review system
- ✓ Push notifications (FCM)
- ✓ Image gallery and slider
- ✓ Multi-language support

## 🏛 Architecture

Provider-based MVVM:

- **Model:** Products, cart, orders
- **View:** Shopping UI, cart, checkout
- **ViewModel:** Business logic, cart management
- **Services:** Payment, notifications, orders

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- payment_gateway packages — payments
- carousel_slider — image slider
- cached_network_image — image caching
- intl — localization
