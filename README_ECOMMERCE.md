## ✅ Features

**User Features:**
- ✓ Browse products by categories
- ✓ Add to cart and wishlist
- ✓ Product search and filters
- ✓ Product variants (size, color)
- ✓ Profile management
- ✓ Order tracking
- ✓ Rating and reviews

**Admin Features:**
- ✓ Add, edit, delete products
- ✓ Product management with images
- ✓ Order management
- ✓ User management
- ✓ Dashboard with analytics
- ✓ Category management

**Common:**
- ✓ Push notifications (FCM)
- ✓ Multi-language support
- ✓ Responsive UI

## 🏛 Architecture

Provider with MVVM and role-based access:

- **Model:** Products, cart, orders, users
- **View:** Dual UI (User & Admin)
- **ViewModel:** Business logic, CRUD operations
- **Services:** Firebase, notifications, image upload

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- image_picker — product images
- cached_network_image — image caching
- intl — localization
