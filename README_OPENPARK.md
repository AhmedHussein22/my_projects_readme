## ✅ Features

- ✓ Find parking spaces near your location
- ✓ Real-time parking availability
- ✓ Reserve and book parking spots
- ✓ Google Maps integration with live tracking
- ✓ Stripe Payment Gateway (Apple Pay, Google Pay)
- ✓ Digital wallet system
- ✓ OTP verification for secure login
- ✓ Parking space management for owners
- ✓ Push notifications (FCM)
- ✓ Rating and review system
- ✓ Secure storage for sensitive data
- ✓ Multi-language support

## 🏛 Architecture

Provider-based MVVM:

- **Model:** Parking data, booking entities, wallet
- **View:** Maps UI, booking interface
- **ViewModel:** Location logic, payment processing
- **Services:** Payment, notifications, secure storage

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- google_maps_flutter — maps
- geolocator — location services
- stripe_payment, flutter_stripe — payment gateway
- flutter_secure_storage — secure data
- sms_autofill — OTP verification
- intl — localization
