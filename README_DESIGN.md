## ✅ Features

- ✓ Engineering consultation booking
- ✓ Construction license services
- ✓ Direct chat with engineers
- ✓ Multi-user system (Client & Engineer)
- ✓ Tap Payment Gateway integration
- ✓ Image picker for project photos
- ✓ Real-time chat
- ✓ Push notifications
- ✓ Rating and review system
- ✓ Responsive UI
- ✓ Multi-language support

## 🏛 Architecture

MVVM with clean code principles:

- **Model:** Service data, user profiles, chat messages
- **View:** Flutter widgets, responsive layouts
- **ViewModel:** Business logic, state management
- **Services:** Payment, chat, notifications, file upload

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- shared_preferences — local storage
- image_picker — photo uploads
- tap_payments — payment gateway
- flutter_chat_ui — real-time chat
- intl — localization
