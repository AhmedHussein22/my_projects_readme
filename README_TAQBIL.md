## ✅ Features

- ✓ Browse and rent properties
- ✓ Advanced search and filtering
- ✓ OpenStreetMap integration
- ✓ REST API with caching
- ✓ Favorites/wishlist system
- ✓ Rating and review system
- ✓ Push notifications (FCM)
- ✓ Multi-flavor support (Dev, Staging, Production)
- ✓ Secure storage for user data
- ✓ Offline caching
- ✓ Responsive UI
- ✓ Multi-language support

## 🏛 Architecture

Clean Architecture with Cubit:

- **Presentation:** Widgets, Cubit
- **Domain:** Use cases, entities
- **Data:** API repository, local cache
- **Core:** Flavors, secure storage

---

## 📦 Key Packages Used

- flutter_bloc / cubit — state management
- firebase_core, firebase_auth, firebase_storage, firebase_messaging — Firebase
- dio — HTTP client
- flutter_map / open_street_map — maps
- flutter_secure_storage — secure storage
- cached_network_image — image caching
- geolocator — location services
- flutter_flavor — environment flavors
- intl — localization
