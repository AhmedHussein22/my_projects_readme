## ✅ Features

- ✓ Listen to the Holy Quran with high-quality audio
- ✓ Download Surahs for offline listening
- ✓ Browse and share beautiful Hidayat (Islamic inspirations)
- ✓ Upload custom Hidayat and share with friends/family
- ✓ Text-to-image conversion for Hidayat
- ✓ Offline audio player with background playback
- ✓ Dark theme support
- ✓ Firebase Remote Config for dynamic content
- ✓ Local database (Sqflite) for offline storage
- ✓ Multi-language support (Localization)
- ✓ Responsive UI across all devices

## 🏛 Architecture

This project follows MVVM principles:

- **Model:** Quran data, Hidayat entities, offline storage
- **View:** Flutter widgets, responsive UI, dark theme
- **ViewModel:** Business logic, audio player control, download management
- **Repository:** Firebase integration, local database access
- **Services:** Audio playback, text-to-image, notifications

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging, firebase_remote_config — Firebase suite
- sqflite — local database
- shared_preferences — persistent storage
- just_audio / audioplayers — audio playback
- cached_network_image — image caching
- text_to_image — Hidayat generation
- flutter_downloader — download manager
- intl — localization
