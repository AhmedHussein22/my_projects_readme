## ✅ Features

- ✓ Multi-role marketplace: marketers, buyers, sellers
- ✓ 7 business systems: jobs, services, products, promo codes, real estate, missions (and more)
- ✓ Commission-based workflows and earnings tracking
- ✓ Secure payments via Fawry integration
- ✓ Real-time notifications (FCM)
- ✓ Video playback for promos & content
- ✓ Offline caching for faster loading and reduced data usage
- ✓ Clean MVVM architecture with testable modules and separation of concerns
- ✓ Localization-ready and responsive UI

## 🏛 Architecture

This project follows MVVM principles combined with Clean Code practices:

- Model: data entities and DTOs (Firestore documents)
- View: Flutter widgets, responsive UI
- ViewModel: business logic, Providers, state exposure
- Repository: abstract data access (Firebase, REST)
- Services: payment gateway, notification, caching, analytics

Benefits:

- Testability, maintainability, and clear separation of concerns.
