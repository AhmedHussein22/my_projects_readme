## ✅ Features

- ✓ Browse and purchase books online
- ✓ AI-based book recommendations
- ✓ Subscription management
- ✓ Shopping cart and wishlist
- ✓ Payment gateway integration (Stripe, Apple Pay, Google Pay)
- ✓ Promo codes and discounts
- ✓ Book preview and PDF viewer
- ✓ Advanced search with debounce
- ✓ Category management
- ✓ Rating and review system
- ✓ Unit testing
- ✓ Multi-language support

## 🏛 Architecture

Provider with MVVM and Unit Testing:

- **Model:** Book entities, cart, orders
- **View:** Book listings, cart, checkout
- **ViewModel:** Business logic with debounce
- **Services:** Payment, subscriptions, recommendations

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- stripe_payment — payment gateway
- in_app_purchase — subscriptions
- flutter_pdfview — PDF viewer
- cached_network_image — image caching
- mockito, flutter_test — unit testing
- intl — localization
