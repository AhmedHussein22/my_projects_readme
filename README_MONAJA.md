## ✅ Features

- ✓ Holy Quran with beautiful interface
- ✓ Daily Azkar (morning, evening, prayer)
- ✓ Audio player for Quran recitations
- ✓ Background audio service
- ✓ Audio caching for offline listening
- ✓ Text-to-image for sharing verses
- ✓ Tasbih counter
- ✓ Prayer times
- ✓ Qibla direction
- ✓ Dark theme support
- ✓ Local storage with Hive
- ✓ JSON-based content
- ✓ Push notifications
- ✓ Multi-language support

## 🏛 Architecture

Clean Architecture with BLoC pattern:

- **Presentation:** Widgets, BLoC, UI logic
- **Domain:** Entities, use cases
- **Data:** Repositories, Firebase, Hive, JSON parsing
- **Core:** Background services, audio player

---

## 📦 Key Packages Used

- flutter_bloc — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- hive, hive_flutter — local database
- just_audio / audioplayers — audio playback
- flutter_background_service — background audio
- text_to_image — verse sharing
- cached_network_image — image caching
- flutter_local_notifications — notifications
- intl — localization
