## ✅ Features

- ✓ Multi-user system (Freelancer & Company)
- ✓ Browse freelancers across diverse expertise
- ✓ Post and bid on projects
- ✓ Real-time chat messaging
- ✓ Video and voice calls (WebRTC/Agora)
- ✓ Secure payment gateway integration
- ✓ Project management and milestones
- ✓ Rating and review system
- ✓ Push notifications (FCM)
- ✓ Portfolio showcase
- ✓ Multi-language support
- ✓ Responsive UI

## 🏛 Architecture

Provider with multi-user architecture:

- **Model:** User types, project entities, chat messages
- **View:** Dual UI (Freelancer & Company)
- **ViewModel:** Business logic, call management
- **Services:** Chat, video/voice calls, payment, notifications

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging, firebase_database — Firebase
- agora_rtc_engine / flutter_webrtc — video/voice calls
- flutter_chat_ui — real-time chat
- payment_gateway packages — payments
- intl — localization
