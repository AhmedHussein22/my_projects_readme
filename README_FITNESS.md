## 🏛 Architecture

Provider-based MVVM:

- **Model:** Workout data, progress tracking
- **View:** Exercise UI, timers, charts
- **ViewModel:** Workout logic, calculations
- **Services:** Notifications, calendar, tracking

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- video_player — exercise videos
- fl_chart — progress charts
- flutter_local_notifications — reminders
- intl — localization
