## ✅ Features

- ✓ Listen to Holy Quran recitations by Mahmoud Al-Malkey
- ✓ Watch Quran videos
- ✓ Browse Islamic photos
- ✓ Download audio and photos for offline access
- ✓ Background audio player
- ✓ Islamic news feed
- ✓ Favorites and wishlist
- ✓ Share content
- ✓ Push notifications (FCM)
- ✓ Dark theme support
- ✓ Multi-language support

## 🏛 Architecture

Provider-based architecture:

- **Model:** Quran data, media content
- **View:** Audio/video player UI
- **ViewModel:** Media management
- **Services:** Download, player, notifications

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- just_audio, video_player — media playback
- flutter_downloader — downloads
- cached_network_image — image caching
- share_plus — sharing
- intl — localization
