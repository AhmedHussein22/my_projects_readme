## ✅ Features

- ✓ Employee profile management
- ✓ Attendance tracking system
- ✓ QR code check-in/check-out
- ✓ Location-based attendance
- ✓ JWT & Refresh Token authentication
- ✓ Biometric authentication (Fingerprint, Face ID)
- ✓ Push notifications (FCM)
- ✓ Admin dashboard
- ✓ Attendance reports
- ✓ Multi-language support
- ✓ Responsive UI

## 🏛 Architecture

Provider with MVVM:

- **Model:** Employee data, attendance records
- **View:** QR scanner, attendance UI
- **ViewModel:** Attendance logic, authentication
- **Services:** QR scanning, location, biometrics

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- qr_code_scanner — QR scanning
- geolocator — location services
- local_auth — biometric authentication
- jwt_decoder — token handling
- intl — localization
