## ✅ Features

- ✓ Listen to Holy Quran recitations by Nasser Al Qatami
- ✓ Watch Quran videos
- ✓ Browse beautiful Islamic photos
- ✓ Download audio and photos for offline access
- ✓ Background audio player
- ✓ Audio caching for faster playback
- ✓ Local database (Hive & Sqflite)
- ✓ Push notifications (FCM)
- ✓ Multi-language support
- ✓ Responsive UI

## 🏛 Architecture

Cubit-based state management:

- **UI Layer:** Flutter widgets, audio player UI
- **State Management:** Cubit for business logic
- **Data Layer:** Firebase, Hive, Sqflite
- **Services:** Audio playback, downloads, notifications

---

## 📦 Key Packages Used

- flutter_bloc / cubit — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- hive, sqflite — local databases
- just_audio / audioplayers — audio playback
- flutter_downloader — download manager
- cached_network_image — image caching
- intl — localization
