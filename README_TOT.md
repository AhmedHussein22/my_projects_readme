## ✅ Features

- ✓ Find qualified teachers from kindergarten to secondary schools
- ✓ Teacher profiles with ratings and experience
- ✓ Video and voice calls (WebRTC/Agora)
- ✓ Real-time chat messaging
- ✓ Booking and scheduling system
- ✓ Calendar integration
- ✓ Payment gateway integration
- ✓ Session management
- ✓ Rating and review system
- ✓ Advanced search and filters
- ✓ Push notifications (FCM)
- ✓ Multi-language support

- Flutter (Mobile)

- Firebase (Firestore, Auth, Storage, Realtime Database, Messaging)

## 🏛 Architecture

Cubit-based state management:

- **UI Layer:** Widgets, video call interface
- **State Management:** Cubit
- **Data Layer:** Firebase, Realtime Database
- **Services:** Video/voice calls, chat, payments

---

## 📦 Key Packages Used

- flutter_bloc / cubit — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging, firebase_database — Firebase
- agora_rtc_engine / flutter_webrtc — video/voice calls
- flutter_chat_ui — real-time chat
- payment_gateway packages — payments
- calendar_view — scheduling
- intl — localization
