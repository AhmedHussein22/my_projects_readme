## 🏛 Architecture

MVVM Pattern with clean code:

- **Model:** Project data, skills, experience
- **View:** Responsive widgets, sections
- **ViewModel:** State management, routing
- **Services:** Firebase hosting, caching, analytics

---

## 📦 Key Packages Used

- go_router — navigation and routing (V2)
- cached_network_image — image caching
- url_launcher — external links
- google_fonts — typography
- animate_do / flutter_animate — animations
- responsive_framework — responsive design
- flutter_svg — SVG support
- visibility_detector — scroll animations
