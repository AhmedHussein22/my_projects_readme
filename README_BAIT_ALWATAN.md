## 🏛 Architecture

Provider-based MVVM:

- **Model:** Property data, news entities
- **View:** Flutter widgets, maps integration
- **ViewModel:** Business logic, API calls
- **Services:** REST API, notifications, maps

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging — Firebase
- google_maps_flutter — maps
- dio — HTTP client
- cached_network_image — image caching
- intl — localization
