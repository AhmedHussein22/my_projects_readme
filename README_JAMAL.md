## ✅ Features

- ✓ Multi-user system (Driver, User, Service Provider)
- ✓ Beauty and fashion service booking
- ✓ Real-time location tracking
- ✓ Google Maps integration
- ✓ Live chat with service providers
- ✓ Tap Payment Gateway integration
- ✓ Rating and review system
- ✓ Push notifications (FCM)
- ✓ Service provider management
- ✓ Driver tracking and assignment
- ✓ Multi-language support
- ✓ Responsive UI

## 🏛 Architecture

Provider with Clean Code:

- **Model:** User types, service data, booking entities
- **View:** Multi-role UI, maps integration
- **ViewModel:** Business logic, location tracking
- **Services:** Payment, chat, notifications, maps

---

## 📦 Key Packages Used

- provider — state management
- firebase_core, cloud_firestore, firebase_auth, firebase_storage, firebase_messaging, firebase_database — Firebase
- google_maps_flutter — maps integration
- geolocator, location — location services
- tap_payments — payment gateway
- flutter_chat_ui — real-time chat
- intl — localization
